Shrunk Attributes

All the attributes to be an ant in Minecraft!

Supported Versions:

26.2+

Tutorial Steps:

  1. The first row is to reset
  2. The second row is to shrink

Commands by Row:

Row 1

1. [impulse] /attribute @p minecraft:scale base reset
2. [chain] /attribute @p minecraft:block_interaction_range base reset
3. [chain] /attribute @p minecraft:entity_interaction_range base reset
4. [chain] /attribute @p minecraft:movement_speed base reset
5. [chain] /attribute @p minecraft:gravity base reset
6. [chain] /attribute @p minecraft:safe_fall_distance base reset
7. [chain] /attribute @p minecraft:jump_strength base reset
8. [chain] /attribute @p minecraft:step_height base reset
9. [chain] /attribute @p minecraft:fall_damage_multiplier base reset
10. [chain] /attribute @p minecraft:air_drag_modifier base reset

Row 2

11. [impulse] /attribute @p minecraft:scale base set 0
12. [chain] /attribute @p minecraft:block_interaction_range base set .28125
13. [chain] /attribute @p minecraft:entity_interaction_range base set .1875
14. [chain] /attribute @p minecraft:movement_speed base set .00625
15. [chain] /attribute @p minecraft:gravity base set .005
16. [chain] /attribute @p minecraft:safe_fall_distance base set .1875
17. [chain] /attribute @p minecraft:jump_strength base set .03625
18. [chain] /attribute @p minecraft:step_height base set .0375
19. [chain] /attribute @p minecraft:fall_damage_multiplier base set 16
20. [chain] /attribute @p minecraft:air_drag_modifier base set 16
